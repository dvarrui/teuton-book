
# Teuton Book

El proyecto **Teuton Book** surge de la necesidad de tener información en español sobre **teuton**, **teuton-get**, etc.

## Índice

1. Tutoriales y casos de uso:
    1. [Tutorial: Nginx](./t01.tutorial_nginx/index.md): Crear un test para Nginx, paso a paso
    2. [Tutorial: GNS3](./t02.tutorial_gns3/index.md): Crear tests para GNS3, paso a paso.
    3. [Tutorial: evaluar código](./t03.tutorial_code/index.md): Crear test para evaluar el funcionamiento de scripts y pequeños programas.
    4. [Tutorial: base de datos y SQL](./t04.tutorial_sql/index.md): Crear test para evaluar la creación de bases de datos y sentencias SQL.
* Explicaciones
    1) [Teuton: Tipos de targets](./d01.tipos_de_targets/index.md): Explicación sobre los distintos tipos de "targets" y su caso de uso.
    2) [Teuton: Eventos](./d02.eventos/index.md): Los eventos definen acciones que disparan cuando se dan las circunstancias adecuadas.
* Proyectos relacionados
    * **teuton**: Test de infraestructura ([repositorio](https://github.com/teuton-software/teuton)).
    * **teuton-get**: Gestor de repositorios de tests ([repositorio](https://github.com/teuton-software/teuton-get)).
